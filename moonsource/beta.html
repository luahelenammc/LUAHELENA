Context architecture from field to form

Moon SourceField before form.

A public reference architecture for turning situated reality into governed sources, reusable procedures, handoffs and other forms of context without forcing everything into one template.

Start with Moon Source SetupExplore the reference repository

Existing evidence only. The public body organizes artifacts that already exist; it does not manufacture a proof case or claim external adoption.

The decision topology

Understand the field. Then choose the form.

Moon Source is not a universal workflow. It is a way to decide what the situation needs, where authority lives and which materialization earns its place.

01Field / reality

See the people, sources, routines, constraints and changes before reducing them to a document.

02Observation / diagnosis

Separate current evidence, friction, contradiction, freshness, risk and missing context.

03Authority / topology

Map which source governs which claim, who owns the work and how the parts relate.

04Proportional form

Choose a living source, skill, handoff, packet, protocol, registry, bridge, surface or archive only when it changes the field.

How the pieces differ

Similar context does not mean identical responsibility.

The architecture stays legible by letting different forms do different jobs.

SourceGoverned context with an authority boundary.
Living sourceUpdateable context with scope, freshness and ownership.
SkillA reusable procedural projection, not a private corpus.
HandoffA transfer of objective, state, constraints and next actions.
ProtocolRepeatable operating rules with boundaries and acceptance.
Public surfaceA human-facing portal that explains or distributes material.

Public boundary

Useful disclosure is still bounded disclosure.

The public layer shows the problem, distinctions, interfaces and existing artifacts. It does not expose private calibration or third-party material for spectacle.

Public

  • Architecture and responsibility distinctions
  • Standalone portables and public evidence
  • Attribution, versions and non-claims

Reserved

  • Private corpora, sensitive material and hidden state
  • Full resolver, compiler and reconciliation heuristics
  • Enough detail to reconstruct protected machinery
