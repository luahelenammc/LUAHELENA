Methodology. Prices shown are official OpenAI API Standard processing, short-context text-token rates, per 1 million tokens, checked September 23, 2026. Cached input, cache writes, Batch, Flex, Fast mode, regional processing and long-context uplifts are intentionally excluded so the comparison remains apples-to-apples. GPT-5.6 Sol's current promotional pricing is stated by OpenAI as available at least through November 21, 2026. These are API prices, not a conversion formula for ChatGPT plan allowances.
