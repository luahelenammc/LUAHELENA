The build is deliberately layered:

`V3 approved document build → V4 house/orientation overlay`

## Privacy decisions

The repository is public. Therefore, safe source records intentionally redact titles for sensitive health, workplace, third-party and intimate material. Source IDs and classification receipts preserve traceability without reproducing private bodies.

The public timeline is a sanitized projection, not an exhaustive mirror.
