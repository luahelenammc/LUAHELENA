# Moonverse V4 — Rebirth

V4 restores the product grammar that precedes the V3 editorial surface.

## Law

- Moonwiki / Notion is the mother source.
- The Moonverse is the curated public house.
- A source record is not a room, article or memory item.
- Rooms, albums, timeline, Atlas and the Mnemonic Machine are projections over safe content.
- The V3 article renderer remains the deep-reading primitive.
- Raw private Notion bodies never enter the public repository.

## Build order

`npm run build` first runs the V3 document generator, preserving the 14 approved article bodies and their publication gates. `v4/build-v4.mjs` then overlays the global V4 experience: Hall, rooms, albums, memory, Moonpedia, timeline, Atlas, search and about.

This is deliberate. Wikiwand-like deep reading remains inside documents; it no longer defines the whole product.
