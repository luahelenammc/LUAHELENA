# Moonverse Public Surface — V2 Content Batch A1

This is the source application for the static Portal Moonverse.

```bash
npm run check
npm run preview
```

The generator writes to `../moonverse/` and never removes `../moonverse/legacy-v0/`. The public output is intentionally conservative: only entries that pass the publication predicate and editorial receipts are rendered.

Batch A1 adds five newly authored/synthesized public entries:

- Moon Source;
- The Sims 1 como casa mental;
- Orkut, MSN e o quarto paralelo;
- Tecnologia, SNES e Olympus D395: a infância digital;
- Ecologia espiritual.

The Wikiwand visual annex was not attached to this execution packet. The V1 article architecture is therefore preserved; no generic Wikiwand redesign was inferred.
